# 10 – Decision Trees

Decision Trees are non-parametric supervised learning algorithms that predict a target by learning a sequence of "if-then" splitting rules from the data. This folder covers the classification splitting criteria (entropy, information gain, Gini impurity), the regression splitting criterion (MSE), and pruning strategies used to control overfitting.
