# 08 – Naïve Bayes

Naive Bayes is a family of probabilistic classifiers based on Bayes' Theorem with a "naive" assumption of conditional independence between features given the class. This folder covers the theorem derivation, the naive independence assumption, the MAP decision rule, and the Gaussian/Multinomial/Bernoulli variants.
