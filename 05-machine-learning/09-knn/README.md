# 09 – K-Nearest Neighbours

K-Nearest Neighbors (KNN) is a simple, non-parametric, lazy learning algorithm used for both classification and regression, based on the idea that similar data points lie close together. This folder covers the algorithm's steps, common distance metrics (Euclidean, Manhattan, Minkowski), and why KNN has no explicit training-time cost function.
