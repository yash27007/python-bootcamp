# Learning Resources

A curated list of free books, blogs, courses, cheatsheets, YouTube channels, and LLM/RAG resources to supplement this course.

> All resources listed here are **free** (or have a substantial free tier). Quality over quantity.

---

## Free Books

| Book | Link | Description |
|------|------|-------------|
| An Introduction to Statistical Learning (ISLR/ISLP) | [statlearning.com](https://www.statlearning.com) | Gold-standard intro to ML; free PDF + Python labs |
| The Elements of Statistical Learning (ESL) | [hastie.su.domains/ElemStatLearn](https://hastie.su.domains/ElemStatLearn/) | Advanced companion to ISLR; free PDF |
| Deep Learning (Goodfellow, Bengio, Courville) | [deeplearningbook.org](https://www.deeplearningbook.org) | The canonical DL textbook; read online for free |
| Dive into Deep Learning (d2l.ai) | [d2l.ai](https://d2l.ai) | Interactive DL with PyTorch/JAX/TF; free and executable |
| Probabilistic Machine Learning (Murphy) | [probml.github.io/pml-book](https://probml.github.io/pml-book/) | Modern Bayesian ML — Books 1 & 2 as free PDFs |
| Mathematics for Machine Learning | [mml-book.github.io](https://mml-book.github.io) | Linear algebra, calculus, probability for ML; free PDF |
| Understanding Deep Learning (Simon Prince) | [udlbook.github.io/udlbook](https://udlbook.github.io/udlbook/) | Visual, up-to-date DL textbook; free PDF (2024) |
| Python Data Science Handbook | [jakevdp.github.io/PythonDataScienceHandbook](https://jakevdp.github.io/PythonDataScienceHandbook/) | Free online; NumPy, Pandas, Matplotlib, scikit-learn |
| Speech and Language Processing (Jurafsky & Martin) | [web.stanford.edu/~jurafsky/slp3](https://web.stanford.edu/~jurafsky/slp3/) | The definitive NLP textbook; free draft PDF |
| Hands-On Machine Learning (Géron) — notebooks | [github.com/ageron/handson-ml3](https://github.com/ageron/handson-ml3) | Full companion notebooks for the O'Reilly book |
| Think Python / Think Stats / Think Bayes | [greenteapress.com](https://greenteapress.com/wp/) | Free PDFs; approachable Python + stats books |
| Neural Networks: Zero to Hero (Karpathy notes) | [karpathy.github.io/neuralnets](https://karpathy.github.io/neuralnets/) | Karpathy's hacker's guide to neural nets |

## Recommended Learning Path

```
1. Python Basics         → This repo, Section 01
2. Statistics            → ISLR Chapter 1-3 + Section 02
3. Data Analysis         → Python Data Science Handbook + Section 03
4. Feature Engineering   → Section 04 + Kaggle courses
5. Core ML               → Andrew Ng ML Specialization + ISLR
6. Deep Learning         → fast.ai Part 1 + d2l.ai
7. NLP                   → Stanford CS224N + HuggingFace Course
8. LLMs from Scratch     → Karpathy's "Zero to Hero" series
9. LLM Applications      → DeepLearning.AI short courses + LangChain docs
10. MLOps                → Full Stack DL + Made With ML
```
