## What You'll Learn

- **Descriptive Statistics** – mean, median, variance, IQR, skewness, kurtosis, correlation
- **Probability** – probability rules, distributions (Normal, Binomial, Poisson), Bayes' theorem, CLT
- **Inferential Statistics** – confidence intervals, hypothesis testing, t-tests, ANOVA, chi-square
