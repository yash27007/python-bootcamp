# 04 – Feature Engineering

Feature engineering is the process of transforming raw data into features that improve model performance. This section covers the most important preprocessing techniques.

| # | Notebook | Description |
|---|----------|-------------|
| 01 | [Missing Values](./01-missing-values.ipynb) | Detecting and imputing missing data (mean, median, KNN, MICE) |
| 02 | [Handling Outliers](./02-handling-outliers.ipynb) | IQR method, Z-score, Winsorization, log transformation |
| 03 | [Data Encoding](./03-data-encoding.ipynb) | Label encoding, one-hot encoding, ordinal encoding, target encoding |
| 04 | [Imbalanced Datasets](./04-handling-imbalanced-dataset.ipynb) | SMOTE, random over/under-sampling, class weights |

## Why Feature Engineering Matters

> "Coming up with features is difficult, time-consuming, requires expert knowledge. Applied machine learning is basically feature engineering." — Andrew Ng

Garbage in, garbage out. Clean, well-engineered features have more impact on model accuracy than the choice of algorithm.
